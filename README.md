# Portfolio • Soluction Imóveis

Portal imobiliário contemporâneo e de alta conversão para a **Soluction Imóveis**, focado no mercado imobiliário do ABC Paulista. Demonstração de arquitetura front-end moderna com Vite, React, TypeScript e Tailwind CSS.

---

## 🚀 Como Executar o Projeto

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
